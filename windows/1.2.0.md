# StreamerX 1.2.0 for Windows and web

- StreamerX is now a Windows app with all five categories and its own player window.
- Your OpenBackend account syncs your library, ratings, watched titles and viewing progress across Windows, Android and the web.
- Windows remembers playback position automatically and restores your sign-in securely.
- Updates include release notes and a verified download before installation.
- The web player now explains provider verification and offers a separate browser player.

Watched controls playback availability and may ask you to verify that you are human or sign into its separate account. Complete that check yourself in the player. Web playback position uses Save position; Windows and Android save it automatically. The Windows installer is not Authenticode signed; update metadata has its own pinned signing key.

Android remains on 1.1.0; its signed APK and update feed are unchanged.
