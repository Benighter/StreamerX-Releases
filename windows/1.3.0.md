# StreamerX 1.3.0 for Windows

- Play stays inside the main StreamerX window, with Back, fullscreen and automatic resume.
- Anime is now a Search filter, and All searches include anime results.
- Favourites are separate from My List and sync with your OpenBackend account.
- Download movies and episodes in the Windows and Android apps, with progress, pause, retry, removal and offline playback.
- Dub preference carries between episodes, falls back to sub when dub is unavailable, and is retained for later episodes.
- Automatic data saving prefers lower quality away from Wi-Fi. Choose a quality to override it; available resolutions depend on the source.
- Existing account sessions, saved titles and viewing progress are preserved.

Watched controls playback, audio availability and verification. StreamerX does not host media or bypass provider access checks. Downloads stay on this device and do not sync as media files. Web playback uses Save position and the browser-player fallback when embedded verification stalls. The Windows installer is not Authenticode signed; updates verify pinned signed metadata and the installer digest.

Web and Android are also available as 1.3.0. Android keeps its existing package and signing certificate.
